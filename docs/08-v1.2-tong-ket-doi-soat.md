## Dữ liệu mới
- `reconciliations` (ví, số app tính, số thực tế, chênh lệch, tờ tiền, giao dịch điều chỉnh) · RLS: chỉ của chính mình. RPC `reconcile_wallet` là SECURITY INVOKER (quy tắc dự án: người dùng không được gọi hàm DEFINER).
- `profiles.settings`: `digest_hour` (0–23 hoặc null = tắt), `remind_days` (0–7, 0 = tắt)
- Cron `titan-notify` mỗi giờ (phút 0), gọi `cron-notify` qua pg_net. URL và secret đọc từ Vault (`titan_functions_url`, `titan_cron_secret`); thiếu secret thì job không làm gì.

## Cài đặt trên cloud (một lần)
```bash
openssl rand -hex 24          # tạo chuỗi bí mật, dùng cho cả 2 chỗ bên dưới
supabase secrets set CRON_SECRET=<chuỗi bí mật>
supabase functions deploy cron-notify --no-verify-jwt
```
Rồi chạy trong SQL Editor của project:
```sql
select vault.create_secret('https://<project-ref>.supabase.co/functions/v1', 'titan_functions_url');
select vault.create_secret('<chuỗi bí mật>', 'titan_cron_secret');
```
Kiểm tra: `select public.titan_notify_tick();` rồi xem `net._http_response`, mong đợi status 200.
